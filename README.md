# 🎮 Number Guessing Game

A beginner-friendly Python project where players try to guess a randomly generated number within a limited number of attempts.

## ✨ Features

- **Three Difficulty Levels:** Easy, Medium, and Hard
- **Random Number Generation:** A new secret number is generated for each game
- **Guessing Hints:** Get hints to guess higher or lower
- **Limited Attempts:** Each difficulty level has a different number of attempts
- **Replay Option:** Play multiple rounds without restarting the program

## 🛠️ Technologies Used

- Python 3
- Random module

## 🎯 Difficulty Levels

| Level | Number Range | Maximum Attempts |
|---|---|---|
| Easy | 1–20 | 10 |
| Medium | 1–50 | 8 |
| Hard | 1–100 | 5 |

## 🚀 How to Run on Google Colab

You can try this project using Google Colab without installing Python locally.

1. Download `number_guessing_game.py` from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Create a new notebook.
4. Copy the Python code into a code cell.
5. Run the cell and follow the prompts.

**Note:** This project uses interactive `input()` prompts. If the game does not work as expected in a Colab cell, run it locally using Python or adapt the input handling for notebook use.

## 💻 How to Run on Your Computer

### Prerequisites

- Python 3 installed on your computer

### Steps

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python3 number_guessing_game.py
```

4. Select a difficulty level and start playing.
